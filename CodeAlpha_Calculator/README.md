# 🧮 CodeAlpha Calculator

A simple, responsive calculator built using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations and follows standard mathematical operator precedence (BODMAS).

## 🌐 Live Demo

[View Calculator](https://miruthikashree.github.io/CodeAlpha_Calculator/)

## ✨ Features

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Standard operator precedence (BODMAS)
- Decimal number calculations
- Clear (AC) and Delete (DEL) functions
- Keyboard support
- Division-by-zero error handling
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive design
- JavaScript – Calculator functionality and logic

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/miruthikashree/CodeAlpha_Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
