# CodeAlpha Internship Tasks

This repository contains three frontend development projects completed as part of my CodeAlpha internship tasks.

## Projects

### 1. Image Gallery
A responsive image gallery built using HTML, CSS, and JavaScript.

**Features:**
- Responsive image layout
- Interactive image navigation
- Lightbox functionality
- Image viewing controls

**Technologies:** HTML, CSS, JavaScript

[View Live Project](https://miruthikashree.github.io/CodeAlpha_ImageGallery/)

### 2. Calculator
A functional calculator built using HTML, CSS, and JavaScript.

**Features:**
- Addition, subtraction, multiplication and division
- Clear and delete functionality
- Real-time calculations
- Keyboard support

**Technologies:** HTML, CSS, JavaScript

[View Live Project](https://miruthikashree.github.io/CodeAlpha_Calculator/)

### 3. Personal Portfolio
A responsive personal portfolio website showcasing my profile, technical skills, education and projects.

**Features:**
- Responsive navigation
- About Me section
- Technologies and Tools
- Projects showcase
- Education details
- GitHub and LinkedIn links
- Scroll reveal animations

**Technologies:** HTML, CSS, JavaScript

[View Live Project](https://miruthikashree.github.io/CodeAlpha_Personal-Portfolio/)
